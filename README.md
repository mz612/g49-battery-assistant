# 红龙G49 PRO鼠标电量助手

面向 **红龙 G49-PRO（2.4G 接收器）** 的轻量 Windows 电量监测工具。无需安装原厂驱动，仅通过只读 HID 查询读取鼠标电量与电压，并直接嵌入 Windows 任务栏显示。

## 下载使用（无需编译）

1. 前往 [Releases 页面](https://github.com/mz612/g49-battery-assistant/releases/latest) 下载最新的 Windows 便携版压缩包（`g49-battery-assistant-*-windows-portable.zip`）。
2. 将压缩包解压到固定文件夹（便携版无需安装，请勿直接在压缩包内运行）。
3. 双击 `红龙G49 PRO鼠标电量助手.exe` 即可运行。

> 运行环境：Windows 10 / 11（内置 .NET Framework 4.x，无需额外安装依赖），适用于受支持的红龙 G49-PRO 2.4G 接收器。

## 功能特点

- **任务栏原生嵌入（`^` 左侧直接显示）**
  - 启动后会自动在任务栏“显示隐藏的图标（`^`）”三角号**左侧**嵌入一个无边框透明的**液面填充鼠标 + 百分比**图标，无需手动从隐藏栏拖出，也不会在桌面产生额外悬浮窗。
  - 无线鼠标轮廓本身充当电量液面容器，自下而上按比例填充，直观区别于笔记本系统电池：
    - **翠绿**：50% – 100%
    - **明黄**：30% – 49%
    - **橙色**：高于提醒阈值且低于 30%
    - **红色警示**：降至设定提醒阈值及以下（默认 **≤ 10%**）且未充电
    - **天蓝 + 迷你闪电**：充电中
    - **灰色空心轮廓（`--`）**：首次启动尚未读取到数据时
  - 开启 Per-Monitor DPI 感知，按任务栏原生分辨率清晰渲染，自动适配深/浅色任务栏与悬停高亮。
  - 检测到全屏游戏、全屏视频、演示模式或任务栏自动隐藏时自动隐身，不遮挡画面；同时在系统托盘保留同步图标用于发送 Windows 低电量通知。

- **5 分钟低功耗轮询 + 空闲跳过（不干扰鼠标休眠）**
  - 启动时立即读取一次；正常使用期间每 **5 分钟**自动刷新一次。
  - **空闲跳过机制**：自动轮询到点时，若检测到超过 **1 分钟**无任何键鼠操作，会直接跳过本次 HID 查询，不向接收器发包，确保不影响鼠标进入或保持休眠；恢复键鼠操作约 **1.5 秒**后自动补查一次。
  - 若开机时接收器尚未就绪、鼠标正在休眠或本次回包超时，仅在恢复阶段按 `15 秒 → 1 分钟 → 5 分钟` 退避重试，读到数据后立即恢复每 5 分钟一次。
  - 已有上一次成功读数时，短暂超时或鼠标休眠不会清空已有电量，而是保留上次数值并在悬停与菜单状态中标明“鼠标可能休眠”或“本次读取失败”。

- **可自定义低电量提醒**
  - 默认在电量降至 **10% 及以下**且未充电时标红警示、播放提示音并发送 Windows 通知；持续低电量期间每 30 分钟提醒一次，充电或电量高于阈值后重置提醒状态。
  - 右键菜单中可随时切换预设阈值（`10%` / `15%` / `20%` / `25%` / `30%` / `50%`）、输入自定义百分比（`1% – 95%`）或关闭提醒，设置自动保存。

## 交互说明

- **悬停图标**：查看当前电量百分比、充电状态与实时电压（mV）。
- **双击图标**：弹出当前状态窗口（电量、充电状态、电压及当前提醒阈值）。
- **右键图标**：
  - **立即刷新**：不受空闲限制，立即主动查询一次电量。
  - **低电量提醒（≤ 10%）**：切换预设阈值、自定义百分比或关闭提醒。
  - **开机启动**：默认关闭；勾选后写入当前用户启动项（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\G49ProBatteryTray`），取消勾选即移除。
  - **复制诊断信息**：复制当前状态、电量、电压、提醒阈值及查询时间到剪贴板。
  - **退出**：安全退出程序并清理托盘与任务栏图标。

## 常见问题

- **为什么电量按 5% 一档变化？**
  这是红龙 G49-PRO 鼠标固件本身的上报粒度（与原厂驱动一致），程序直接展示固件上报值，不做额外取整；悬停或双击图标可查看精确到 `1 mV` 的实时电池电压。
- **暂时读取不到电量怎么办？**
  先移动一下鼠标将其从休眠中唤醒，等待自动补查或右键图标点击“立即刷新”即可。

## 已验证的只读协议

本程序不调用 Windows 通用电池接口，也不会写入或修改任何鼠标配置（DPI、按键、灯光、配对等）。它向 G49-PRO 2.4G 接收器的 HID 命令端点（`VID_3554` / `PID_F54C`、`PID_F54D`、`PID_F54F` 的 `MI_01&Col05`）仅发送原厂驱动的只读 `BatteryLevel` 查询帧：

```text
08 04 00 00 00 00 00 00 00 00 00 00 00 00 00 00 49
```

- `0x04` 为电池查询命令，末字节为校验和 `(0x55 - sum(bytes[0..15])) & 0xff`。
- 回包第 6、7、8、9 字节分别对应电量百分比、充电状态、电压高字节、电压低字节（实测如 `25%`、未充电、`3633 mV`）。
- 当前实现仅针对 2.4G 无线接收器；蓝牙直连模式走系统 BLE 电池服务，不与此工具混用。

## 从源码编译（可选）

源码为单文件 [G49电量助手.cs](G49电量助手.cs)（配以程序图标 [app.ico](app.ico)），无任何第三方依赖，直接使用 Windows 自带的 .NET Framework 4.x `csc.exe` 编译。

在 Windows 上进入项目目录，双击 `编译.bat` 即可生成带图标的 `红龙G49 PRO鼠标电量助手.exe`。
